# ASCII LUMINESCENCE — 設計の全体

## 1. 世界と構成
- 1人称3DのASCIIローグライト。1回の探索は1時間前後。迷宮は毎回生成される。
- **層**：石の迷宮（深度1〜2）→ 大洞窟 → 古代の廃墟 → 溶岩の海 → 深淵（〜深度13）。層ごとに階の大きさが違う。
- **特別な階**（深度の間に挟む。上書きしない）：地下の町（深度2の後、全回復）、大広間（深度3か4の後）、
  神託所（深度5の後、全回復）、放棄された砦（深度9か10の後）。本道は全17階。
- **支道**（主がいる）：墓所（不死の王）、獣の巣（年老いた竜）、水没神殿（深みの主）、蜘蛛の巣（蜘蛛の女王）、蛇の穴（ナーガの女王）。
- **異界**：氷の洞窟、魔術師の研究所、火山。火山の火口（最大3つ）は、20〜40秒ごとに噴き上がり、溶岩が0.3秒に1マスずつ流れ出す（プレイヤーの近くと、生き物のいるマス・歩いて向かっているマス・体がかかるマスには流れない。流せなかったマスは、後で空いたら流す）。12秒たつと、0.15秒に1マスずつ引く。
- **目的**：主が持つ伝説の物（燭台・鐘・鏡）を3つ集めて最深部へ行き、現れる王の影を倒す。勝利の言葉「光は戻った」。
- **階の流れ**：交差点（本道の中ほどの一番広い部屋。中にいると明るく、方向の矢印が遠くまで届く）と、その近くの寄り道。階段の番人（約3割の階、倒すまで階段が封じられる）。

## 2. 戦い：武器は「どう届けるか」
**原則**：どの攻撃も、手から照準へ向かって、見える何かが飛ぶ。剣も、近い敵に刃が当たり、三日月の斬撃が飛ぶ。
攻撃の形が違うものは、特性ではなく**別の武器**にする。

| 武器 | 持ち方 | 左クリック | 右クリック |
|---|---|---|---|
| 小剣 | 片手 | 振る。目の前の敵に刃、三日月の斬撃が約5m飛ぶ（刃が当たった敵には当たらない） | ― |
| 風走りの細剣 | 片手 | 約3m駆け抜けて斬り、突きの刃（約8m）を飛ばす | ― |
| 遠鳴りの両手剣 | 両手 | 横に広い三日月（約4m） | 溜めて、加速する大きな三日月 |
| 短弓 | 両手 | 素早く射る | 引き絞って、強く貫く一矢 |
| 雨降らしの長弓 | 両手 | 遠くへ一矢 | 狙った所に、壁を越えて矢の雨 |
| 早撃ちの連弩 | 片手 | 3本続けて撃つ | ― |
| 樫の杖 | 片手 | 弧を描いて飛び、落ちた所で弾ける光の弾 | ― |
| 水晶の杖 | 片手 | 照らし続ける光の帯 | ― |
| 星降りの杖 | 片手 | 狙った所に、少し遅れて光の柱が降る | ― |
| 満ち月の長杖 | 両手 | 光の弾 | 溜めるほど育つ光の月（大きさは最大3倍。特性で伸びる） |

- **両手持ち**：両手の枠を合わせて、最大6つ。性質の交互・重ね・発動も、両手で共有する。
- **斬撃の形**：振った面の上にできる三日月（小剣は約35°傾いた面、右手は右上→左下、左手は鏡。両手剣はほぼ水平）。
  中央が前へ膨らみ、両端が手前に反る。飛ぶほど広がり、終わりで薄れる。当たる幅は、見た目の幅とそろえる。
- **手元の武器**：画面の下の角から入り、端で切れる（目安：片手は下35%、両手は下45%）。敵と同じく、大きめの文字を輪郭に沿って並べる。
  手は必要な所だけ（剣の拳、弓を持つ手と引く手、素手）。杖は柄の上と頭だけ。弓は中央より左に縦に構え、しなりは奥へ。
- **当たりの手応え**：押し返し（武器で違う。重い敵ほど動かない）、ヒットストップ、ひるみ、強い一撃で構えを崩す。

### 武器の特性（届け方の持ち味。ランダムではない）
- 武器ごとに**代表の特性2つ**が決まっていて、Lvは**見つけた深さ**で決まる（深度1〜3:0、4〜6:1、7〜9:2、10〜13:3。宝物庫・強敵は+1、主は+2、最大4）。
- **鍛えの祭壇**（大洞窟・古代の廃墟・溶岩の海に1か所ずつ）と主の祭壇で、持っている武器の特性を1つ上げる・足す。
- Lvで素直に伸びる（節目なし）。例：数は Lv1〜5で +1,+1,+2,+2,+3。

| 武器 | 特性の候補（先頭2つが代表） |
|---|---|
| 小剣 | 数・飛距離・刃の幅・押し返し |
| 風走りの細剣 | 駆ける距離・駆ける間・残像・突きの飛距離 |
| 遠鳴りの両手剣 | 刃の幅・溜めの速さ・押し返し・よろめき |
| 短弓 | 数・貫き・ホーミング・矢の速さ |
| 雨降らしの長弓 | 雨の広さ・引きの速さ・降る長さ・数 |
| 早撃ちの連弩 | 数・精密・装填の速さ・押し返し |
| 樫の杖 | 数・跳ね返り・弾の速さ・押し返し |
| 水晶の杖 | 帯の長さ・跳ね返り・収束 |
| 星降りの杖 | 数・柱の大きさ・降る速さ・引き寄せ |
| 満ち月の長杖 | 満ちる速さ・月の大きさ・潮・数 |

- 名前の色：特性なしは普通、特性ありは淡い水色、Lv5の特性があれば金色。名前に特性は書かない（説明に出す）。
- 特性は、この表の物だけ（src/lib/runes.ts の TRAITS）。武器に付けるのも、コードで名前を読む（TL・tv・wTL）のも、表にある名前だけ（単体テスト traits.test.mjs が確かめる）。

## 3. ルーン：「何を届けるか」
| 種類 | 中身 | 枠のきまり |
|---|---|---|
| 性質 | 火・氷・雷・毒 | 1つの手に2種類まで。2種類なら交互に撃つ。同じ性質を重ねると強まる（1:100%、2:140%、3:170%、4:190%、同じ手の中だけ） |
| 発動 | かわした時・倒した時 | 1つの手に1つまで |
| 効き方 | 連鎖・広がり・長さ（普通と金色の強い版） | 同じ物は2つまで |
- 手の枠は最初2つずつ、空の枠で4つまで。体の枠（護符）は最初は閉じていて、空の枠で2つまで開く。
- 性質の反応：蒸気（火×氷）・爆炎（火×毒）・過熱（火×雷）・砕氷（氷×雷）・凍える毒（氷×毒）・毒の伝播（雷×毒）（魔導書に記録）。
- 袋に入る効き方のルーンが、袋の同じ普通の版と重なると、1つの強い版にまとまる。

## 4. 護符（体の枠）
疾風・身軽・早口・灯火・癒し・余韻・忍び足・守り。どれも数字を強める物。

## 5. 回復
- 自然回復なし。受けたダメージの6割は「取り戻せる体力」（約4秒で薄れる）になり、自分の攻撃で敵を打つと取り戻せる。
- 回復の場所：祭壇の癒し（最大の7割）、階段を降りる（2割）、癒しの泉（1つにつき1回全回復。25%の階に1つ。交差点のある階では、交差点の近くの寄り道が2つ以上になるまで足される）、地下の町と神託所（全回復）。

## 6. 成長
- **経験**：敵を倒すと入る（1体 = 1+⌊√体力/3⌋、強敵×3、主×10）。必要な経験は 4, 8, 22, 36, 50…（14ずつ増える）。
- **レベルアップ**：その瞬間に時間が止まり、3つから1つ（恩恵2つ＋ルーンか護符1つ）。0.4秒はクリックを受け付けない。
  最初のレベルアップは、戦い方が変わる恩恵だけを出す。
- **恩恵（13）**：頑丈な体・身軽な詠唱・返しの一撃・追い風・巻き返し・火攻め・冷え込み・裂ける雷・溜めの一撃・
  背水・持ち替えの冴え・焦熱（代償）・捨て身（代償）。2回まで取れる。
- **目標**：敵の7割を倒して進むと、神託所でLv5。
- **最大体力**：レベルでは伸びない。新しい層に初めて入るたびに +4（大洞窟・古代の廃墟・溶岩の海・深淵）。

## 8. 方向の矢印
手の少し上の、床に寝かせた円盤から、まっすぐの向きを示す（道順は示さない）。前の物は奥へ、後ろの物は手前へ伸びる。円盤の傾きは見上げる・見下ろすに合わせるが、限りの中に収める（見上げても消えず、見下ろしても真円にならない）。近いほど短く太く。見えている物には出さない。
- いつも出す：`>` 階段（金）。
- 一度見た後に出す：`>` 支道（紫）、`0` 異界の門。
- 20m以内なら出す（交差点の中では1.5倍）：`_` 祭壇、`T` 鍛えの祭壇、`~` 泉、`#` 宝物庫、`*` 強敵の褒美、`+` 墓。
  泉・宝物庫・強敵の褒美・墓は、まだ見ていない間は `?`（色はそのまま）で出す。

新しい反応×3、初めての忘れられた獣×4。試練1つにつき +25%（倒れても効く）。

**墓**：倒れた時、結果の画面で武器・ルーン・護符を1つ遺せる。次の探索で同じ深さの寄り道に墓が現れる。
拾うと、武器は特性Lvが1つずつ下がり、強い版は普通の版になる。直前の1つだけ残る。

**結果の画面**：死因、場所（深度と層）、Lv・倒した敵・時間、伝承の内訳と合計・累計・使える伝承、次の解放まで、墓の選択。
背景を暗くし、ほかの表示を隠す。

## 10. 決めた方針
- 武器 = 届け方（形・数・速さ・飛距離・幅・曲がる・跳ねる・貫く・押し返し）。ルーン = 届けるもの（性質・発動・効き方）。
- ランダムな数値の付加効果は付けない（拾う数が少ない周回型では、選ぶ楽しさではなく運の雑音になる）。
- 探索中の成長は、武器に縛らない（Witchfire の Arcana、Hades の恩恵に近い）。武器ごとの変化は、ときどき（鍛えの祭壇）。
- 持ち替えても損をしない（深い所の武器ほど特性が高い）。1本を使い続けるのも、立派な遊び方。
- 解放は、強さではなく「選べる物」を増やす。
- 文言は日本語。素朴で自然に。英語の直訳、凝りすぎた名前は避ける。

## 11. 残っている課題・次の候補
- **職業**：始まりの武器の組み合わせ（今は小剣と樫の杖）。
- **別の武器にする予定の形**：回し斬りの曲刀、砕けの杖（弾が割れる）、散り矢の弓、屈折の杖。ほかの武器の種類（短剣・斧・槍・槌）。
- **護符**：動きを攻撃に変える物（Witchfire の指輪のように「かわすと武器に性質が宿る」など）、代償つきの護符。
- **飛び道具を撃つ敵**：いれば、飛び道具を斬り返す特性（小剣の「返し刃」。まだ無い）を作る意味が出る。プレイヤーにかかる状態異常も候補。
- **調整**：神託所の時点のレベルが目標より高い（敵の7割を倒して進むと、実際に測って Lv7）、恩恵の名前、手元の拳の形（まだ塊に見える）、押し返し・ヒットストップ・
  回復量・取り戻せる体力・泉の数・階段の番人の割合などの数値。
- **通しのプレイでの確認**（1回の探索を最後まで遊んで確かめる）：
  - 剣の三日月の斬撃：見た目の幅と当たる幅が合っているように見えるか。刃が当たった敵に斬撃が当たらないことが、実際に動かして分かるか。飛ぶ距離（小剣は約5m）が短すぎないか。
  - 両手持ち：左右で撃ち方が違うことが伝わるか。枠6つを組み合わせて迷わないか。
  - レベルアップのペース：敵の7割を倒して進んだ時に、神託所でのレベルが目標に近いか。選ぶ恩恵が途中で尽きないか。
  - 伝承のペース：何回の探索で、最初の解放（10から15）と一番高い解放（30）に届くか（まだ目標は決めていない）。
- **掃除と修理をする小さな生き物の道探し**：灰や焼け落ちた扉へ、道を探さずに真っすぐ向かう（少しの揺らぎだけ）。壁の向こうの扉や灰を
  選ぶと、壁に張り付いたまま動かなくなる。行ける所だけを選ぶ（歩いて行けるかの調べ方を使う）か、しばらくして着かなければあきらめる。
